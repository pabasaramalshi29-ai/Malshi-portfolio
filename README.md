# Malshi Samarasinghe — Portfolio

Personal software developer portfolio built with semantic HTML5, modern responsive CSS3, and vanilla JavaScript.

## Highlights

- **Responsive Across Devices**: Fluid layout with a mobile slide-over navigation drawer, adaptive hero portrait framing, and touch-friendly controls.
- **Complete Portfolio Sections**: Hero showcase, About & metrics, Skills & tech stack, Filterable Projects gallery, Engineering Focus pillars, and interactive Contact section.
- **Real GitHub Projects**: Showcases repositories from [`@pabasaramalshi29-ai`](https://github.com/pabasaramalshi29-ai), including the Hyperlocal Weather Impact & Community Alert Web App, FoodieGo, MIRAVA RESORT, Employee Management System (EMS), Banking Query System, Tech-Care, and Interactive To-Do List.
- **Interactive Features**: Category project filters, animated skill bars and stat counters, scroll progress bar, one-click email copy, and validated contact form.

## Files

- `index.html` — Semantic page markup and SEO metadata
- `styles.css` — Dark editorial theme, layout grid, animations, and responsive breakpoints
- `script.js` — Mobile drawer, project filtering, scroll reveal, copy-to-clipboard, and form handling
- `malshi.png` — Profile portrait
